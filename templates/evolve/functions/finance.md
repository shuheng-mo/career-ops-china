# 职能包：财务岗（总账 / 税务 / 财务分析 / 财务 BP / 业财）

`config/profile.yml` 里 `evolve.function: finance` 时使用。证据维度参考了财务职业咨询常用的人岗匹配能力框架。

## 证据维度

| 维度 | 面试官的问题 | 账本里要有什么 |
|---|---|---|
| 核算 | 「你负责几个主体？月结多久？」 | 主体数量和结构、准则（PRC / IFRS）、关账周期、凭证量级 |
| 税务 | 「节税那笔具体是什么？」 | 税种、申报主体数、稽查应对次数、每项纳税调整的类型和金额 |
| 财务分析 | 「你的分析推动了什么决策？」 | 分析对象、发现、谁用了结论、决策结果 |
| 内控流程 | 「你搭过什么流程？」 | SOP 清单、穿行测试次数、建议被采纳的例子 |
| 系统工具 | 「ERP 用到什么程度？」 | 系统名、你做过的配置 / 映射 / 自动化 |
| 团队管理 | 「带过几个人？」 | 带队次数、团队规模、你的角色 |
| 业财沟通 | 「怎么说服业务的？」 | 一次具体的跨部门推动：分歧点、你的理由、结果 |
| 业务体量 | 「公司 / 盘子多大？」 | 收入或 GMV 量级（注明口径）、业务覆盖范围 |

## 高风险 claim 信号（优先挖）

- 节税 / 降本金额没有逐项构成
- 「缩短 X%」没有前后耗时和测算口径
- 「采纳率约 X%」没有分母
- 汇报线、职级说法与组织架构对不上（背调高发点）
- 公司体量数字记不清——宁可写「约 X」并注明口径，不要估高

## 参考样本

### 金额构成题

> 【年度】【N 个】主体汇算清缴中，我识别的纳税调整包括【差异类型 1，约 X 万】、【差异类型 2，约 X 万】，合计约【X 万】，其中【某项】是我主动发现的，不是外部提示的。

### 自动化前后对比题

> 原来每月要手工【动作】，涉及【N 份文件或步骤】，约【X 小时】。我用【工具】改成【做法】，现在约【X 分钟】，按【口径】测算缩短约【X%】。

### 跨部门推动题

> 我发现【问题】，影响是【每月要额外做什么 / 什么合规风险】。对方一开始【顾虑】，我用【合规 / 税务 / 成本】角度说明后争取到【资源】，最终【改动】，上线后【省掉了什么】。

### 体量题

> 公司【年份】的【GMV / 收入】约【X】（口径：【GMV / 收入】），我直接负责的部分是【范围】，量级约【X】。
